# `ankify-cli`

This is a Cargo package, named `ankify` (though its parent directory is named `ankify-cli` to differentiate it from the Typst package).

It provides one binary crate and one library crate, both named `ankify`.

-   The binary crate provides a command-line interface for calling the library crate's functionality.
-   The library crate provides functions for extracting Anki cards out of Typst documents that use the `ankify` Typst package.
